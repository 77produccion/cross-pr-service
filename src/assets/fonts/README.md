# Tipografías locales

- `archivo-latin.woff2`: Archivo, latin subset, pesos 500–700. Dirección A.
- `dm-sans-latin.woff2`: DM Sans, latin subset, pesos 400–700. Texto general.
- `anton-latin.woff2`: Anton, latin subset, peso 400. Dirección B.
- `instrument-serif-latin.woff2`: Instrument Serif, latin subset, peso 400. Dirección C.
- `instrument-serif-italic-latin.woff2`: Instrument Serif italic, latin subset. Dirección C.
- `playfair-display-latin.woff2` y `playfair-display-italic-latin.woff2`: Playfair Display, latin subset, peso 500. Títulos de la propuesta aprobada.
- `manrope-latin.woff2`: Manrope, latin subset, pesos 600–800. Detalles de la propuesta aprobada.

Las fuentes de direcciones anteriores se conservan como originales, pero ya no se cargan en el sitio. Los nuevos WOFF2 proceden de Google Fonts; no se hacen peticiones a Google en runtime.

Todas las familias se distribuyen bajo SIL Open Font License 1.1.
